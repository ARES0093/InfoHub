# InfoHub
A smart, dual-mode chatbot built with Gradio that gives real-time news updates or personalized guidance using Groq's LLaMA 3 and NewsAPI. Clean UI, emoji-friendly, and easy to run locally. Just ask — it listens, thinks, and responds!




# 🧠✨ AI News + Guide Bot

A smart, friendly chatbot that keeps you updated with the **latest news** or gives **personalized guidance** — all powered by **Groq's LLaMA 3 API** and **NewsAPI**. The UI is built using **Gradio** for a smooth, modern chat experience.

---

## 📌 Features

✅ **Two Modes**  
- 🗞️ **News Bot**: Fetches live news based on your query and provides a sentiment-aware summary.  
- 🧭 **General Guide**: Acts like a helpful assistant who can explain, suggest, and guide.

✅ **Gradio-based UI** – Clean, responsive, and modern  
✅ **Real-time News** from [NewsAPI](https://newsapi.org)  
✅ **Groq-powered LLaMA 3 responses** for human-like replies  
✅ 💬 **Chat history display** with emojis and markdown  
✅ 🧹 Easy clear/reset button  
✅ 🔐 API Key secured via `.env` file

---

## 🧠 Tech Stack

| Layer       | Technology          |
|-------------|---------------------|
| LLM Backend | Groq API (LLaMA 3)  |
| News API    | NewsAPI.org         |
| UI          | Gradio (Python)     |
| Env Vars    | python-dotenv       |
| Hosting     | Local or Cloud      |
